# Guideline de Boas Práticas de Código

## Naming

- [ ] Use nomes descritivos e consistentes para variáveis, funções e classes.
- [ ] Evite 'números mágicos', números largados sem contexto.
- [ ] Evite abreviações que não sejam amplamente conhecidas. 

## Functions
- [ ] Defina um propósito claro: uma função deve ter uma única responsabilidade.
- [ ] Use nomes descritivos: escolha nomes que indiquem o que a função faz.
- [ ] Mantenha a função curta: funções devem ser simples e conscisas.
- [ ] Limite os parâmetros: use apenas os parâmetros necessários.
- [ ] Refatore regularmente: revise e melhore suas funções ao longo do tempo.
